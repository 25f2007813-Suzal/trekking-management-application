# Trekking Management Application
A Trekking Management Application is a platform that helps organize and manage trekking activities, including registrations, schedules, routes, and participant tracking.


## Tech Stack Used
- **Backend:** Flask
- **Database:** Sqlite, Flask-Sqlalchemy
- **Frontend:** HTML5, CSS(Bootstrap), Jinja2
- **Security:** Flask-Login

## Prerequisites
- Python 3
- pip

## Default Admin Account
- **Username:** `admin`
- **Password:** `admin123`

## Project Structure
- `app.py`: Main Flask application entry point
- `database.py`: Database module
- `models.py`: Database schema definitions
- `routes/`: Url endpoints and request handling
- `controllers/`: Buisness logic for url endpoints
- `templates/`: Jinja2 HTML file
